# LeetCode Solutions Vault

Personal collection of LeetCode solutions.

Problems are scaffolded, tested, and submitted from VS Code using
[leetknight](https://github.com/DNT-Khoa/leetknight).

## Structure

Each problem lives in its own folder generated by leetknight, typically containing
the problem statement, a solution file, and example test cases.

## Language

- Java

## Tooling

- [leetknight](https://github.com/DNT-Khoa/leetknight) — VS Code extension for
  scaffolding, testing, and submitting LeetCode problems
