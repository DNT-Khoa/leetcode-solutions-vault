# LeetCode Solutions Vault

Personal collection of LeetCode solutions in Python.

Problems are scaffolded, tested, and submitted from VS Code using
[leetgrasp](https://github.com/DNT-Khoa/leetgrasp).

## Structure

Each problem lives in its own folder generated by leetgrasp, typically containing
the problem statement, a Python solution file, and example test cases.

## Language

- Python 3

## Tooling

- [leetgrasp](https://github.com/DNT-Khoa/leetgrasp) — VS Code extension for
  scaffolding, testing, and submitting LeetCode problems in Python
